# Milestone 1 — שלד הפרויקט ומסגרת הממשק — תוכנית

## מטרה
להקים אתר שאפשר להריץ מקומית ולבדוק בגודל מסך של מובייל. האתר יכלול את שני המסכים, "בית" ו"אודות", במבנה של ה-Wireframes ובשפה החזותית של ה-Style Guide וה-Mockups. המשחק עצמו עדיין לא פעיל: הוא נבנה ב-Milestone 2.

## דרישה מוקדמת — Node.js
במחשב לא מותקן Node.js (נבדק: הפקודות `node` ו-`npm` לא נמצאו). צריך אותו כדי להריץ את Vite.
- לפני תחילת הבנייה: לעצור ולבקש מהמשתמש להתקין את גרסת ה-LTS מ-https://nodejs.org (מתקין רגיל ל-Mac), ולהדריך אותו צעד אחר צעד.
- אחרי ההתקנה, לוודא ש-`node -v` ו-`npm -v` עובדים.

## הסטאק (לפי ARCHITECTURE.md)
- Vite + Vanilla TypeScript + HTML + CSS. בלי Framework.
- גופן Heebo מותקן מקומית דרך החבילה `@fontsource/heebo` ולא מ-Google Fonts, כדי שלא תהיה תלות ב-CDN (נדרש ל-Offline ב-Milestone 4).
- **לא** נכלל ב-Milestone הזה: `vite-plugin-pwa` (Milestone 4), Vitest ולוגיקת משחק (Milestone 2), localStorage (Milestone 3), GitHub Actions/Pages (בזמן הפריסה).

## קבצים ליצירה
```
package.json            ← סקריפטים: dev, build, preview; תלויות: vite, typescript, @fontsource/heebo

src/

├── router.ts           ← ניתוב פשוט מבוסס hash: "#/" = בית, "#/about" = אודות (כפתור "אחורה" של הדפדפן עובד)
├── screens/
│   ├── home.ts         ← יצירת מסך הבית
│   └── about.ts        ← יצירת מסך אודות
├── ui/icons.ts         ← אייקונים כ-SVG בקוד (Line icons, קו 2px, פינות מעוגלות): מידע, גביע, הפעלה, רמקול, חזרה, חץ
├── ui/illustrations.ts ← איורים פשוטים כ-SVG בקוד: אסטרונאוט, כוכב לכת
└── styles/
    ├── tokens.css      ← משתני CSS: צבעים, טיפוגרפיה, ריווחים, פינות, צללים (מה-Style Guide)
    ├── base.css        ← איפוס בסיסי, גופן, רקע חללי, פריסת Mobile-First
    └── components.css  ← כפתורים, אריחים, כרטיסים, רשימה, סרגל ניווט, כותרת עליונה
```

בנוסף: הוספת `dist/` ל-`.gitignore` אם היא חסרה. אין צורך ב-`.env`, כי לפי ARCHITECTURE אין סודות או מפתחות.

## מסך הבית (`#/`)
לפי Wireframe "מסך הבית" ו-Mockup:
- **שורה עליונה:** אייקון מידע (ℹ) בצד שמאל, שמוביל לאודות. בצד ימין "השיא האישי" עם אייקון גביע והמספר, שמוביל לאזור השיא במסך אודות. ב-Milestone הזה המספר הוא 0 קבוע, והערך האמיתי יגיע ב-Milestone 3.
- **לוח משחק 2×2 במרכז:** ארבעה אריחים בכחול, אדום, צהוב וירוק, עם פינות מעוגלות, קו מתאר בהיר וזוהר בצבע האריח. האריחים יהיו כפתורים (`<button>`) מושבתים, בלי פעולה. סדר הצבעים יהיה כמו ב-Mockup: כחול למעלה משמאל, אדום למעלה מימין, צהוב למטה משמאל, ירוק למטה מימין. מכיוון שהעמוד בכיוון RTL, צריך להגדיר את הסדר במפורש כדי שהמיקום יישאר זהה.
- **כפתור ראשי "התחל"** עם אייקון ▶, בצורת pill ו-Gradient סגול-מג'נטה. ב-Milestone הזה הלחיצה לא עושה דבר. אין להמציא התנהגות.
- **סרגל ניווט תחתון:** "השיא שלי" (גביע) ו"אודות" (ℹ). שני הפריטים מובילים למסך אודות. "השיא שלי" גולל לכרטיס השיא.
- **רקע חללי:** Gradient כהה (Dark Navy אל Galaxy Purple), כוכבים שנוצרים ב-CSS, ואיור קטן של כוכב לכת ואסטרונאוט בפינה, כך שלא יפריעו לאריחים.

## מסך אודות (`#/about`)
ה-PRD מגדיר רק שני מסכים, ולכן מסך אודות אחד משלב את המידע על המשחק עם השיא וההיסטוריה (לפי הערת ההתאמה ב-DESIGN.md):
- **כותרת "אודות"** עם אייקון חזרה (‹) שמחזיר לבית.
- **אזור מידע:** איור אסטרונאוט וכוכב לכת, הכותרת "משחק זיכרון קלאסי" והטקסט "זכרו את הרצף, שחזרו אותו והגיעו לשיא!".
- **כרטיס "השיא האישי"** עם גביע והמספר (0 קבוע ב-Milestone הזה).
- **כותרת "היסטוריית המשחקים"** ואזור הרשימה. ב-Milestone הזה מוצג מצב ריק, למשל "עדיין אין משחקים שמורים". **אין להציג נתוני דמה.** את מבנה השורה (ניקוד, תוצאה, תאריך ושעה, חץ) מכינים ב-CSS לשימוש ב-Milestone 3.

## שפה חזותית — ערכים מה-Style Guide
- **צבעים:** Galaxy Purple `#4B2E83`, Magenta `#FF2D9B`, Electric Blue `#2E7BFF`, Turquoise `#00C2D1`, Sunset Orange `#FF8A3D`, Starlight Yellow `#FFD93D`, Rocket Red `#FF4757`, Light Purple `#C9B6FF`, Dark Navy `#0F172A`, Slate `#475569`, Cool Gray `#94A3B8`, Light Gray `#E2E8F0`, Background `#F8FAFC`.
- **אריחים:** כחול לפי Electric Blue, אדום לפי Rocket Red, צהוב לפי Starlight Yellow. לירוק אין HEX במקור, ולכן נבחר ירוק שתואם חזותית ל-Mockup. זו בחירה ויזואלית, לא דרישה.
- **טיפוגרפיה:** Heebo. H1 40/48 Bold, H2 32/40 Bold, H3 24/32 SemiBold, Body 16/24, Small 14/20, Caption 12/16 Medium. במובייל מותר להקטין כותרות ולשמור על היחסים ביניהן.
- **פינות:** 12px לכרטיסים, 50% לעיגולים, 24px (pill) לכפתורים.
- **צללים:** `0 4px 12px rgba(79,46,131,.1)` ו-`0 8px 24px rgba(79,46,131,.15)`. Glow צבעוני רק לאריחים, לכפתור הראשי ולסמלי מצב.
- **ריווחים:** 8, 12, 16, 24, 32px.
- **ניגודיות:** טקסט לבן על רקע כהה. כרטיס ההיסטוריה בהיר עם טקסט Navy, כמו ב-Mockup.

## פריסה
- Mobile-First. התוכן מוגבל לרוחב של בערך 480px וממורכז, כדי שגם במסך מחשב יוצג כמו טלפון. אין התאמה ייעודית לטאבלט או למחשב.
- גובה מלא של המסך (`100dvh`), כשסרגל הניווט התחתון צמוד לתחתית במסך הבית.
- אזורי לחיצה בגודל 44px לפחות.

## מה לא בונים כאן (כדי לא לחרוג מה-Milestone)
- אין לוגיקת משחק, צלילים, הצגת רצף או מצבי הצלחה, כישלון וניצחון (Milestone 2).
- אין שמירה או קריאה מ-localStorage (Milestone 3).
- אין Manifest, Service Worker ומסך Offline (Milestone 4).
- אין מסכים נוספים מעבר לבית ואודות.

## בדיקה עצמית בזמן הבנייה
1. `npm install`, אחר כך `npm run build` (צריך לעבור בלי שגיאות TypeScript), ואז `npm run dev`.
2. לפתוח בדפדפן ה-Preview בגודל מובייל (375×812) ולצלם את שני המסכים.
3. להשוות למבנה ה-Wireframes ולמראה ה-Mockups.
4. לבדוק את הניווט: ℹ, "השיא שלי", "אודות" וקישור השיא מובילים לאודות; החץ וכפתור "אחורה" של הדפדפן מחזירים לבית.
5. לוודא `dir="rtl"`, שכל הטקסטים בעברית, ושאין שגיאות ב-Console.
6. לסגור את השרת בסיום.
7. לעדכן את "פקודות הרצה" ב-CLAUDE.md: הרצה עם `npm run dev`. בדיקות: אין עדיין (Vitest יתווסף ב-Milestone 2).
8. לסמן 🟡 ליד Milestone 1 ב-MILESTONES.md.

## Definition of Done (מתוך MILESTONES.md)
- הפרויקט נבנה ורץ בסביבת הפיתוח בלי שגיאות חוסמות.
- מסך הבית ומסך „אודות” מוצגים בעברית וב-RTL.
- פריסת המסכים ורכיבי הממשק תואמים ל-Wireframes ולשפה החזותית ב-DESIGN.md.
- אפשר לעבור בין מסך הבית למסך „אודות” ולחזור.
- אין מסכים או יכולות מוצר מעבר ל-PRD.
