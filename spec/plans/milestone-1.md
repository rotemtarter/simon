# Milestone 1 — שלד הפרויקט ומסגרת הממשק — תוכנית

## מטרה
להקים אתר שאפשר להריץ מקומית ולבדוק בגודל מסך של מובייל. האתר יכלול את שני המסכים, "בית" ו"אודות", במבנה של ה-Wireframes ובשפה החזותית של ה-Style Guide וה-Mockups. המשחק עצמו עדיין לא פעיל: הוא נבנה ב-Milestone 2.

## דרישה מוקדמת — Node.js
במחשב לא מותקן Node.js (נבדק שוב בעת כתיבת התוכנית: הפקודות `node` ו-`npm` לא נמצאו). צריך אותו כדי להריץ את Vite.
- לפני תחילת הבנייה: לבדוק שוב. אם עדיין חסר — לעצור ולבקש מהמשתמש להתקין את גרסת ה-LTS מ-https://nodejs.org (מתקין רגיל ל-Mac), ולהדריך אותו צעד אחר צעד.
- אחרי ההתקנה, לוודא ש-`node -v` ו-`npm -v` עובדים.

## הסטאק (לפי ARCHITECTURE.md)
- Vite + Vanilla TypeScript + HTML + CSS. בלי Framework.
- גופן Heebo מותקן מקומית דרך החבילה `@fontsource/heebo` (משקלים 400, 500, 600, 700) ולא מ-Google Fonts, כדי שלא תהיה תלות ב-CDN (ARCHITECTURE 2.2 — נדרש ל-Offline ב-Milestone 4).
- **לא** נכלל ב-Milestone הזה: `vite-plugin-pwa` (Milestone 4), Vitest ולוגיקת משחק (Milestone 2), localStorage (Milestone 3), GitHub Actions/Pages (בזמן הפריסה).

src/

├── router.ts           ← ניתוב פשוט מבוסס hash: "#/" = בית, "#/about" = אודות; כתובת לא מוכרת → בית

├── ui/illustrations.ts ← איורים כ-SVG בקוד, בהשראת spec/illustrations.png: אסטרונאוט, כוכבי לכת, שביט
└── styles/

    ├── base.css        ← איפוס בסיסי, גופן, רקע חללי, פריסת Mobile-First

- `.gitignore` כבר מכיל `node_modules/` ו-`dist/` — אין צורך לשנות אותו.
- אין צורך ב-`.env` / `.env.example`: לפי ARCHITECTURE אין סודות או מפתחות.
- הסיבה לאיורי SVG בקוד ולא לשימוש ישיר ב-`illustrations.png`: התמונה קטנה, עם רקע לבן ומכילה כמה איורים יחד — לא מתאימה לרקע כהה.

## מסך הבית (`#/`)
לפי Wireframe "מסך הבית" ו-Mockup:
- **שורה עליונה:** אייקון מידע (ℹ) בצד שמאל, שמוביל לאודות. בצד ימין "השיא האישי" עם אייקון גביע והמספר, שמוביל לכרטיס השיא במסך אודות. ב-Milestone הזה המספר הוא 0 קבוע (כמו ב-Wireframe), והערך האמיתי יגיע ב-Milestone 3.
- **לוח משחק 2×2 במרכז:** ארבעה אריחים בכחול, אדום, צהוב וירוק, עם פינות מעוגלות, קו מתאר בהיר וזוהר עדין בצבע האריח. האריחים הם כפתורים (`<button>`) מושבתים, בלי פעולה, עם `aria-label` בעברית ("כחול" וכו'). סדר הצבעים כמו ב-Mockup: כחול למעלה משמאל, אדום למעלה מימין, צהוב למטה משמאל, ירוק למטה מימין. מכיוון שהעמוד ב-RTL, הסדר יוגדר במפורש (Grid עם מיקום קבוע) כדי שהמיקום יישאר זהה.
- **כפתור ראשי "התחל"** עם אייקון ▶, בצורת pill ו-Gradient סגול-מג'נטה עם Glow. ב-Milestone הזה הלחיצה לא עושה דבר — אין להמציא התנהגות.
- **סרגל ניווט תחתון:** "השיא שלי" (גביע) בצד שמאל ו"אודות" (ℹ) בצד ימין, כמו ב-Wireframe. שני הפריטים מובילים למסך אודות; "השיא שלי" גולל לכרטיס השיא. (פריט "בית" שמופיע בדוגמת הניווט ב-Style Guide לא נכלל — ה-Wireframe מנצח על המבנה.)
- **רקע חללי:** Gradient כהה (Dark Navy אל Galaxy Purple), כוכבים שנוצרים ב-CSS, משטח כוכב לכת בתחתית, כוכב לכת קטן ואסטרונאוט יושב בפינה השמאלית התחתונה (כמו ב-Mockup), כך שלא יפריעו לאריחים ולכפתור.
- שורת הסטטוס "9:41" שבתמונות היא חלק מציור הטלפון — לא בונים אותה.

## מסך אודות (`#/about`)
ה-PRD מגדיר רק שני מסכים, ולכן מסך אודות אחד משלב את המידע על המשחק עם השיא וההיסטוריה (לפי הערת ההתאמה ב-DESIGN.md), לפי הסדר:
- **כותרת "אודות"** ממורכזת, עם אייקון חזרה (‹) בצד שמאל כמו ב-Wireframe, שמחזיר לבית.
- **אזור מידע:** איור אסטרונאוט מרחף וכוכב לכת, הכותרת "משחק זיכרון קלאסי" והטקסט "זכרו את הרצף, שחזרו אותו והגיעו לשיא!".
- **כרטיס "השיא האישי"** עם Gradient סגול-כחול, גביע והמספר (0 קבוע ב-Milestone הזה). לכרטיס יהיה `id` כדי שהקישורים ממסך הבית יגללו אליו.
- **כותרת "היסטוריית המשחקים"** וכרטיס רשימה בהיר (טקסט Navy, כמו ב-Mockup). ב-Milestone הזה מוצג בתוכו מצב ריק: "עדיין אין משחקים שמורים". **אין להציג נתוני דמה.** את מבנה השורה (ניקוד מימין, תוצאה, תאריך ושעה, חץ משמאל) מכינים ב-CSS לשימוש ב-Milestone 3.

## שפה חזותית — ערכים מה-Style Guide
- **צבעים:** Galaxy Purple `#4B2E83`, Magenta `#FF2D9B`, Electric Blue `#2E7BFF`, Turquoise `#00C2D1`, Sunset Orange `#FF8A3D`, Starlight Yellow `#FFD93D`, Rocket Red `#FF4757`, Light Purple `#C9B6FF`, Dark Navy `#0F172A`, Slate `#475569`, Cool Gray `#94A3B8`, Light Gray `#E2E8F0`, Background `#F8FAFC`.
- **אריחים:** כחול לפי Electric Blue, אדום לפי Rocket Red, צהוב לפי Starlight Yellow. לירוק אין HEX במקור, ולכן ייבחר ירוק שתואם חזותית ל-Mockup — בחירה ויזואלית, לא דרישה.
- **טיפוגרפיה:** Heebo. H1 40/48 Bold, H2 32/40 Bold, H3 24/32 SemiBold, Body 16/24, Small 14/20, Caption 12/16 Medium. במובייל מותר להקטין כותרות ולשמור על היחסים ביניהן.
- **פינות:** 12px לכרטיסים, 50% לעיגולים, 24px (pill) לכפתורים.
- **צללים:** `0 4px 12px rgba(79,46,131,.1)` ו-`0 8px 24px rgba(79,46,131,.15)`. Glow צבעוני רק לאריחים, לכפתור הראשי ולסמלי מצב.
- **ריווחים:** 8, 12, 16, 24, 32px.
- **ניגודיות:** טקסט לבן על רקע כהה.

## פריסה
- Mobile-First. התוכן מוגבל לרוחב של כ-480px וממורכז, כדי שגם במסך מחשב יוצג כמו טלפון. אין התאמה ייעודית לטאבלט או למחשב.
- גובה מלא של המסך (`100dvh`); במסך הבית סרגל הניווט צמוד לתחתית, ומסך אודות נגלל.
- אזורי לחיצה בגודל 44px לפחות.

## החלטות לתיעוד כ-ADR ב-ARCHITECTURE.md (בזמן הבנייה)
- **ADR-1: ניתוב מבוסס hash** — פשוט, בלי ספרייה, עובד ב-GitHub Pages בלי הגדרות שרת, וכפתור "אחורה" של הדפדפן עובד.
- **ADR-2: גופן ואיורים מקומיים** — Heebo מ-`@fontsource/heebo` ואיורי SVG בקוד, כדי שלא תהיה תלות במשאבים חיצוניים (הכנה ל-Offline).

## מה לא בונים כאן (כדי לא לחרוג מה-Milestone)
- אין לוגיקת משחק, צלילים, הצגת רצף, כותרת "שלב X מתוך 10" או מצבי הצלחה, כישלון וניצחון (Milestone 2).
- אין שמירה או קריאה מ-localStorage (Milestone 3).
- אין Manifest, Service Worker והודעת Offline (Milestone 4).
- אין מסכים נוספים מעבר לבית ואודות.

## בדיקה עצמית בזמן הבנייה
1. `npm install`, אחר כך `npm run build` (צריך לעבור בלי שגיאות TypeScript), ואז `npm run dev`.
2. לפתוח בדפדפן ה-Preview בגודל מובייל (375×812) ולצלם את שני המסכים.
3. להשוות למבנה ה-Wireframes ולמראה ה-Mockups; לתקן פערים.
4. לבדוק את הניווט: ℹ, "השיא האישי", "השיא שלי" ו"אודות" מובילים לאודות (השיא — לכרטיס השיא); החץ וכפתור "אחורה" של הדפדפן מחזירים לבית; רענון בכל מסך נשאר באותו מסך.
5. לוודא `dir="rtl"`, שכל הטקסטים בעברית, שאין גלילה אופקית, ושאין שגיאות ב-Console.
6. לוודא שאין בקשות רשת לשרתים חיצוניים (גופן ואיורים נטענים מקומית).
7. לסגור את השרת בסיום.
8. לעדכן את "פקודות הרצה" ב-CLAUDE.md: הרצה — `npm run dev`; בדיקות — אין עדיין (Vitest יתווסף ב-Milestone 2).
9. להוסיף את ה-ADRs ל-ARCHITECTURE.md ולסמן 🟡 ליד Milestone 1 ב-MILESTONES.md.

## Definition of Done (מתוך MILESTONES.md)
- הפרויקט נבנה ורץ בסביבת הפיתוח בלי שגיאות חוסמות.
- מסך הבית ומסך „אודות” מוצגים בעברית וב-RTL.
- פריסת המסכים ורכיבי הממשק תואמים ל-Wireframes ולשפה החזותית ב-DESIGN.md.
- אפשר לעבור בין מסך הבית למסך „אודות” ולחזור.
- אין מסכים או יכולות מוצר מעבר ל-PRD.
